> 작성일: 2026-11-04

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | SNS Admin |

## 2. 기능 범위

### 2.1 포함 기능

| 메뉴 | 세부 기능 |
|------|-----------|
| **대시보드** | 가입자 추이, 게시물 추이, 신고 현황, 최근 활동 요약 카드 |
| **회원** | 목록(검색·필터·페이지네이션), 상세(프로필·피드·팔로워·팔로잉·제재 이력) |
| **피드(게시물)** | 목록(검색·필터·정렬), 상세(미디어·댓글·좋아요·신고 탭) |
| **신고** | 목록(처리 상태 필터), 상세(신고 내용·대상 프리뷰·처리 액션) |
| **공지사항** | 목록, 상세(조회), 작성/수정, 삭제 |
| **FAQ** | 목록, 상세, 작성/수정/삭제 |

### 2.2 제외 기능

- 상품 / 카테고리 관리
- 포인트 / 출금 관리
- 광고주 대시보드
- 쇼핑라이프 / 삭제 콘텐츠

## 4. 공통 기능 요구사항

### 4.1 인증

- 로그인 폼 (이메일 + 비밀번호)
- 로그인 성공 시 localStorage에 토큰 저장 (목업: 항상 성공 처리)
- 미인증 접근 시 `/login` 리다이렉트
- 사이드바 로그아웃 버튼

### 4.2 레이아웃

- 좌측 사이드바 (네비게이션 메뉴, 로고, 관리자 정보, 로그아웃)
- 상단 헤더 (페이지 타이틀, 사이드바 토글)
- 사이드바 접기/펼치기 (아이콘 모드)
- 반응형: 모바일 사이드바 오버레이

### 4.3 공통 UI 컴포넌트

- Button (primary / secondary / danger / ghost)
- Input / Textarea / Select
- Badge / Tag
- Table (컬럼 정의 기반, TanStack Table)
- Pagination
- Modal (Confirm, Form)
- Toast 알림
- DatePicker
- SearchSection + TableSection 래퍼
- StatCard (대시보드 통계)
- Skeleton (로딩 스켈레톤)

### 4.4 데이터

- 모든 API 요청은 MSW(Mock Service Worker)로 가로채 목업 데이터 반환
- 목업 데이터: `src/mocks/mockData.ts` 중앙 관리
- TanStack Query로 서버 상태 관리 (캐시, 로딩, 에러 상태)

## 5. 기능별 상세 요구사항

### 5.1 대시보드

- 통계 카드: 총 회원수, 오늘 가입자, 총 게시물수, 미처리 신고
- 차트 1: 최근 30일 일별 가입자 추이 (LineChart)
- 차트 2: 최근 30일 일별 게시물 추이 (BarChart)
- 최근 신고 목록 (5건, 링크)
- 최근 가입 회원 목록 (5건, 링크)

### 5.2 회원 목록/상세

**목록**
- 검색: 닉네임, 이메일
- 필터: 상태(활성/정지/탈퇴), 가입일 범위
- 정렬: 가입일, 최근 접속일
- 테이블 컬럼: 프로필 이미지, 닉네임, 이메일, 상태, 가입일, 최근 접속일

**상세**
- 프로필 섹션: 이미지, 닉네임, 이메일, 소개, 상태, 가입일
- 탭: 피드 목록 / 팔로워 / 팔로잉 / 제재 이력
- 액션: 계정 정지 / 정지 해제 / 강제 탈퇴 (Confirm 모달)

### 5.3 피드 목록/상세

**목록**
- 검색: 내용, 작성자 닉네임
- 필터: 공개 여부, 작성일 범위
- 테이블 컬럼: 썸네일, 작성자, 내용 미리보기, 좋아요수, 댓글수, 공개여부, 작성일

**상세**
- 미디어 섹션: 이미지/영상 슬라이드
- 게시물 정보: 작성자, 내용, 태그, 위치, 작성일
- 탭: 댓글 / 좋아요 / 신고
- 액션: 게시물 블라인드 처리 / 해제

### 5.4 신고 목록/상세

**목록**
- 필터: 처리 상태(미처리/처리됨), 신고 유형(게시물/댓글/회원)
- 테이블 컬럼: 신고 대상 유형, 신고자, 신고 사유, 처리 상태, 신고일

**상세**
- 신고 정보: 신고자, 신고 대상, 사유, 신고일
- 대상 프리뷰: 게시물/댓글/회원 미리보기
- 처리: 경고/블라인드/계정정지/무시 선택 → 처리 메모 입력 → 처리 완료

### 5.5 공지사항

- 목록: 제목, 작성일, 공개여부
- 상세: 제목, 내용(HTML 렌더), 작성일, 공개여부
- 작성/수정: 제목 Input + 내용 Textarea + 공개여부 Toggle
- 삭제: Confirm 모달 후 삭제

### 5.6 FAQ

- 카테고리 필터 (계정/게시물/신고/기타)
- 목록: 카테고리, 질문, 작성일
- 상세: 질문, 답변, 카테고리
- 작성/수정: 카테고리 Select + 질문 Input + 답변 Textarea
- 삭제: Confirm 모달 후 삭제

## 6. 비기능 요구사항

| 항목 | 목표 |
|------|------|
| TypeScript | strict 모드, any 사용 금지 |
| 코드 스타일 | ESLint + Prettier |
| 접근성 | 주요 인터랙션 요소에 aria 속성 |
| 디자인 | Tailwind CSS 기반, 다크/라이트 무관 (라이트 고정) |
| 경로 별칭 | `@/` → `src/` |
| 환경변수 | 없음 (서버 URL 불필요) |
